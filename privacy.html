한눈에 보기

업로드에 필요한 정보를 Google 및 YouTube에 전송하고, 인증 정보는 운영자의 PC에서 관리합니다. 접근 권한은 Google 계정에서 직접 해제할 수 있습니다.

01 도구와 운영자

my-uploader(이하 “도구”)는 운영자 leegori가 개인 PC에서 본인이 소유하거나 관리 권한을 가진 YouTube 채널에 영상을 업로드하기 위해 사용하는 개인용 도구입니다. 도구는 YouTube API Services를 이용합니다.

02 처리하는 정보와 목적

도구는 사용자가 Google OAuth로 승인한 권한 범위 안에서 영상 업로드에 필요한 정보만 처리합니다.

  • OAuth 인증 정보: 액세스 토큰과 갱신 토큰 등 API 접근을 위한 인증 정보
  • 업로드 정보: 사용자가 선택한 영상 파일, 제목, 설명, 공개 설정 등
  • 작업 결과: 업로드 결과와 영상 식별자 등 작업 수행에 필요한 API 응답

이 정보는 지정한 채널에 영상을 업로드하고 업로드 작업을 관리하는 데 사용됩니다. Google 계정 비밀번호는 Google의 인증 화면에서 처리되며 도구가 수집하거나 저장하지 않습니다.

03 정보의 전송과 공유

계정 인증, 토큰 갱신 및 영상 업로드 과정에서 필요한 정보가 Google 및 YouTube에 전송됩니다. Google에서 처리하는 정보에는 Google 개인정보처리방침이 적용됩니다.

도구는 정보를 판매하거나 광고 타기팅에 사용하지 않으며, 위 기능 수행에 필요한 Google 및 YouTube 전송 외의 제3자 배포를 목적으로 사용하지 않습니다. 업로드한 영상의 공개 범위는 사용자가 지정한 YouTube 공개 설정에 따릅니다.

04 개인 PC에서의 보관

OAuth 인증 정보는 운영자의 개인 PC에 보관합니다. 도구를 계속 이용하는 동안 인증 상태를 유지하는 데 사용하며, 더 이상 필요하지 않을 때는 저장된 인증 정보를 삭제하고 접근 권한을 해제할 수 있습니다.

업로드 원본, 설정 및 작업 결과가 PC에 남아 있다면 운영자가 해당 파일을 직접 관리하고 삭제합니다. 이 소개 웹사이트는 OAuth 토큰이나 영상 파일을 입력받거나 저장하지 않습니다.

05 접근 권한 해제와 정보 삭제

  1. Google 계정의 연결 관리에서 my-uploader의 접근 권한을 해제합니다.
  2. 개인 PC에서 도구가 저장한 인증 정보와 더 이상 필요하지 않은 설정·작업 결과 파일을 삭제합니다.
  3. YouTube에 이미 업로드한 영상이나 관련 정보를 삭제하려면 YouTube 또는 YouTube Studio에서 별도로 삭제합니다.

접근 권한 해제는 PC에 저장된 파일을 자동으로 삭제하지 않습니다. 반대로 PC의 파일 삭제만으로 Google 계정의 접근 권한이 해제되거나 YouTube의 업로드 영상이 삭제되는 것은 아닙니다.

06 이 웹사이트의 정보 처리

이 웹사이트에는 회원가입, 입력 폼, 광고 또는 별도의 방문자 분석 도구를 두지 않습니다. 운영자는 이 페이지를 통해 방문자의 계정 정보나 업로드 자료를 직접 수집하지 않습니다.

웹사이트는 GitHub Pages에서 호스팅됩니다. 사이트 제공 및 보안 운영 과정에서 GitHub가 IP 주소 등 접속 관련 정보를 처리할 수 있습니다. 자세한 내용은 GitHub 개인정보처리방침을 확인해 주세요.

07 문의와 변경 사항

개인정보 처리에 관한 문의는 운영자의 GitHub 저장소 Issues를 이용해 주세요. 공개 게시판이므로 비밀번호, OAuth 토큰, 계정 인증 정보 등 민감한 정보를 게시하지 마세요.

기능이나 정보 처리 방식이 변경되면 이 페이지의 내용과 시행일을 갱신합니다. 도구를 이용하기 전에 최신 내용을 확인해 주세요.
