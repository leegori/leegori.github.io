my-uploader는 운영자의 개인 PC에서 실행되는
YouTube 영상 업로드 도구입니다.

HOW IT WORKS

필요한 작업에만, 필요한 권한을.

01 / 연결

Google 계정으로 승인

Google OAuth를 통해 YouTube 업로드에 필요한 범위의 접근 권한을 직접 승인합니다. Google 비밀번호를 도구에 입력하지 않습니다.

02 / 업로드

내 PC에서 실행

개인 PC에서 선택한 영상과 업로드 정보를 Google 및 YouTube에 전송합니다. 이 도구는 YouTube API Services를 이용합니다.

03 / 관리

연결과 데이터를 직접 관리

인증 정보는 개인 PC에 보관합니다. 더 이상 사용하지 않을 때는 로컬 인증 정보를 삭제하고 Google 계정에서 접근 권한을 해제할 수 있습니다.

YOUR CHANNEL, YOUR CONTROL

이용 전 확인해 주세요.

개인용으로 운영되는 도구이며, 이 소개 페이지에서 계정 연결이나 영상 업로드를 제공하지 않습니다. 도구 이용 시 개인정보처리방침을 확인해 주세요. YouTube API Services를 이용하는 사용자는 YouTube 서비스 약관의 적용을 받으며 이에 동의해야 합니다.
